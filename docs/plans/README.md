# Plans

Work that is planned but not implemented yet: reviews, proposals and their findings.
A plan is a working document. Check items off and add notes as work lands.

## Lifecycle

1. **Open:** a new file `YYYY-MM-DD-short-title.md`, with a status line at the top.
2. **In progress:** items are checked off as they merge, each with the commit or PR.
3. **Done:** when every item is either done or explicitly dropped, set the status to
   *Done*. Any decision the plan settled becomes an ADR in [../adr/](../adr/), and
   the plan links to it.

Plans are not deleted when done; they record what was considered and why.
